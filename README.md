# Kreate releases

Downloads of Kreate, a 3D modelling application. See **Releases** for the
latest version.

Each release has, for each platform:

- `kreate-<platform>.zip` — `kreate` and `kreate-mcp`, unpacked anywhere and run.
  Installed copies of Kreate read this repository to update themselves.
- `kreate-<platform>.tar.gz` — the same, as a tarball.

The source is developed in a separate repository; this one holds only releases.
